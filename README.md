> 项目的跨对话状态、决策、评测指标、已知问题与变更日志见 [`PROJECT_MEMORY.md`](PROJECT_MEMORY.md)。

`G001_장연_AIAgent.ipynb`에서 검증된 핵심 로직을 단계적으로 분리한 로컬 우선 프로젝트입니다. 원본 Notebook은 수정하지 않았습니다.

현재 baseline은 Notebook의 결정적 fallback 규칙을 모듈화한 버전입니다. 사용자가 로그인과 최종 제출을 직접 담당하고, 프로그램은 확인된 개인정보와 학력을 입력합니다.

## 현재 지원 범위

- 성명, 성, 이름
- 생년월일
- 휴대폰 번호
- 이메일
- 한국 5자리 우편번호
- 주소, 상세주소
- 보유 기술, 기술 스택
- 대학교·대학원, 학위, 전공, 복수/부전공
- 입학 구분·입학년월, 졸업 구분·졸업년월
- 평점·만점, 본교/분교, 소재지

경력, 자기소개서, 민감한 신원 정보는 아직 자동 입력 범위에 포함하지 않습니다.

## 반드시 지키는 안전 원칙

- 아이디와 비밀번호를 자동 입력하지 않습니다.
- CAPTCHA와 MFA를 처리하거나 우회하지 않습니다.
- 최종 제출 버튼을 자동으로 누르지 않습니다.
- 페이지에 이미 입력된 값은 덮어쓰지 않습니다.
- 웹페이지의 문구를 Agent 지시로 실행하지 않습니다.
- 불확실하거나 부작용 가능성이 있는 항목은 사용자에게 맡깁니다.
- 이력서 원문, 개인정보, API Key를 로그에 기록하지 않습니다.

## 2단계: 핵심 Python 모듈

`src/job_agent_core/`에는 다음 기능이 있습니다.

- 텍스트형 PDF의 크기, 페이지 수, 암호화 여부 검사와 텍스트 추출
- 보수적인 한국어 이력서 규칙 파서
- `full / family / given / middle` 이름 모델
- Notebook fallback과 동일한 한국어·영문 개인정보/학력 필드 규칙 매핑
- OpenAI에 종속되지 않는 `MappingProvider` 인터페이스
- 기존 웹페이지 값 보존을 기본값으로 하는 입력 계획
- 이름 분리 확인, 이름 재조합 검사, 브라우저 입력값 재검증
- 텍스트 입력, select, radio, 자동완성, 사용자 정의 선택, 날짜 컨트롤 계획
- 다음 단계 버튼과 최종 제출 버튼의 엄격한 구분
- HTTPS, 도메인, 리디렉션에 대한 기본 보안 정책

핵심 모듈 테스트:

```bash
PYTHONPATH=src .venv/bin/python -m unittest discover -s tests -v
```

테스트는 LLM을 호출하거나 실제 채용 사이트에 접속하지 않습니다. 두 개의 브라우저 통합 테스트는 로컬 HTML로 입력·회독 검증과 자동 제출 금지를 검사합니다.

## 3단계: 로컬 API와 작업 상태

FastAPI 서비스는 다음 기능을 제공합니다.

- 작업 생성과 상태 조회
- PDF 이력서 업로드 및 메모리 내 분석
- 이름 분리 결과 확인
- Notebook baseline 규칙으로 개인정보·학력 입력 계획 생성
- 작업 취소와 민감 데이터 제거

SQLite에는 작업 ID, 대상 호스트명, 상태, 사용 가능한 항목 이름만 저장합니다. PDF 내용, 이력서 값, 쿼리를 포함한 전체 URL은 프로세스 메모리에만 두고 작업 취소 또는 서비스 종료 시 제거합니다.

API만 실행하려면 24자 이상의 임의 로컬 토큰을 환경 변수로 설정합니다.

```bash
export JOB_AGENT_API_TOKEN="24자-이상의-임의-로컬-토큰으로-교체"
PYTHONPATH=src .venv/bin/python -m uvicorn job_agent_core.api:create_app \
  --factory --host 127.0.0.1 --port 8765 --no-access-log
```

## 4단계: PySide6 데스크톱 사용자 화면

`src/job_agent_core/desktop.py`는 PySide6로 만든 한국어 네이티브 데스크톱 화면입니다. 기존 React 화면은 `ui/`에 회귀 참고용으로 남겨 두었지만 기본 실행 경로에서는 사용하지 않습니다.

- HTTPS 채용 페이지 URL 검사
- PDF 형식과 10MB 크기 제한 확인
- 지원 항목별 인식 결과 표시
- 한국 이름의 성/이름 분리 확인
- 누락 항목, 경고, 안전 원칙 표시
- 작업 취소와 메모리 데이터 제거
- `다시`를 눌러도 프로그램을 종료하기 전까지 선택한 이력서 유지
- 항상 위에 표시 옵션과 검출·입력·확인·소요 시간 상태 표시

데스크톱 화면은 임의로 생성한 로컬 접근 토큰을 메모리에서만 사용합니다. 이력서 원문과 개인정보는 외부 서비스로 전송하지 않습니다.

### 처음 한 번 설치

```bash
uv pip install --python .venv/bin/python -e .
```

### API와 화면 한 번에 실행

프로젝트 디렉터리에서 실행합니다.

```bash
.venv/bin/python run_local.py
```

브라우저에서 `http://127.0.0.1:5173/`을 엽니다. 종료하려면 실행 중인 터미널에서 `Ctrl+C`를 누릅니다.

PySide6 데스크톱 창이 바로 열립니다. `브라우저 열기`로 Playwright 브라우저를 열고, 로그인과 본인 인증은 직접 완료한 뒤 `현재 페이지 확인`을 누릅니다.

### 프런트엔드 테스트와 빌드

```bash
cd ui
npm test
npm run build
```
